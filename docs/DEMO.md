# Repeatable Demonstration

## Default: deterministic credential-free demo

Use this path at a venue unless the deployed environment has already passed its rehearsal. It calls no cloud AI and uses no microphone.

1. Open Wings and state: “This is demo mode. I’ll use typed/sample text; no microphone or cloud AI is involved.”
2. Show the private profile and explain that the separate public card exposes only enabled fields.
3. Start the prefilled conversation with Alex Morgan.
4. Press the microphone-shaped demo button once; it inserts the deterministic product-research scenario rather than recording.
5. Select **Get me unstuck**. Show the question, transition, and experience cue, then play one with on-device speech if appropriate.
6. End the conversation. Show the bounded summary and whether notes were saved.
7. Open the public-card preview, QR/link/vCard alternatives, and confirmation-before-save contact flow.
8. Open **Privacy & how it works**, show diagnostics, then demonstrate **Review stored data**. Use a disposable demo identity before demonstrating destructive account erasure.

## Live-path consent

Before microphone capture, say what is sent, where, why, and how to stop it. Obtain affirmative awareness from every participant, enable the in-app confirmation, point out the persistent recording badge, and demonstrate pause. Never secretly record a bystander or use live capture where local policy prohibits it.

## Failure choreography

- Cloud unavailable: switch to demo mode; do not pretend preset cues came from Gemma.
- Microphone/permission failure: type the recent sentence; manual help remains available.
- Speech provider failure: pause recording, type context, and continue with text/fallback cues.
- App backgrounded: show that recording paused and requires an explicit resume.
- Session expired: start a new session; no microphone is automatically restored.
- QR/camera failure: open or share the HTTPS link/vCard instead.

Always distinguish implemented behavior, deterministic fallback, and pending physical/cloud validation.
